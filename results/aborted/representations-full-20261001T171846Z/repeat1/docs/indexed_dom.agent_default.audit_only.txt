/ Client.request()
Client.request()
Send an HTTP request and return a
[145]<a />
	Response
. This is the low-level method that all verb helpers such as
client.get()
and
client.post()
call internally.
[157]<button />
	Copy
response = client.request(
    method, url, *, params=None, headers=None, json=None,
    data=None, timeout=DEFAULT_TIMEOUT, follow_redirects=True,
    max_redirects=20, retry=None,
)

Note:
Since version 3.0,
timeout
applies to the entire request rather than to each socket operation.
Returns
Response
object. The body is read eagerly unless you use
[332]<a />
	Client.stream()
Raises
ConnectTimeout
— the connection could not be established in time.
TooManyRedirects
— more than
max_redirects
redirects were followed.
InvalidURL
— the URL could not be parsed.
Deprecated:
The
verify_ssl
argument was removed in 3.2. Configure TLS on the
Client
instead.
Example
[379]<button />
	Copy
from ferrite import Client, RetryPolicy

with Client(base_url="https://api.example.com") as client:
    response = client.request(
        "PATCH", "/orders/42",
        json={"status": "shipped"},
        retry=RetryPolicy(attempts=3),
    )
    response.raise_for_status()
